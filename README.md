## Instalación en 5 minutos (con la app Downloader)

### 1. Instala Downloader
- **Google TV / Android TV:** abre la **Play Store**, busca **Downloader** (ícono naranja, de AFTVnews) e instálala.
- **Fire TV Stick:** en la lupa 🔍 busca **Downloader** e instálala.

### 2. Dale permiso a Downloader para instalar apps (solo la primera vez)
- **Google TV / Android TV:** Configuración → Sistema → Acerca de → presiona 7 veces **"Compilación del SO de Android TV"** hasta que diga que eres desarrollador. Luego Configuración → Apps → Seguridad y restricciones → **Fuentes desconocidas** → activa **Downloader**.
- **Fire TV Stick:** Configuración → Mi Fire TV → Acerca de → presiona 7 veces el nombre del dispositivo. Luego Mi Fire TV → Opciones para desarrolladores → **Instalar apps desconocidas** → activa **Downloader**.

### 3. Descarga StreamMID
Abre Downloader y en el cuadro escribe el código:

```
7395455
```

Si el código no funciona, escribe este link completo:

```
https://github.com/jarros280381-byte/streammid/releases/latest/download/StreamMID.apk
```

Presiona **Ir / Go**. Cuando termine, presiona **Instalar** y luego **Listo** (puedes borrar el archivo descargado, ya no se necesita).

### 4. Entra con tu cuenta
Abre **StreamMID** y escribe el **servidor, usuario y contraseña** que te dio StreamMID (o tu link M3U). Se guardan y no tienes que volver a escribirlos.

## Cómo se usa
- **TV en vivo:** categorías a la izquierda, canales en medio y vista previa con la guía (qué pasan ahorita y qué sigue) a la derecha. **OK** = pantalla completa · **↑ ↓** = cambiar de canal.
- **Guía completa:** botón **📅 Guía** o la tecla **Menú ☰** del control.
- **Películas y Series:** **OK** pausa · **← →** adelanta o regresa 10 s (dejándolo apretado, 1 minuto).
- **Favoritos ⭐:** deja apretado **OK** sobre un canal, película o serie.

## Actualizaciones
La app avisa sola cuando hay una versión nueva: presiona **Actualizar**. La primera vez se abre la pantalla **"Instalar apps desconocidas"**: baja hasta **StreamMID**, actívala, regresa con el botón **atrás** y vuelve a presionar **Actualizar**. Eso es solo una vez.

## ¿Problemas?
- **"App no instalada"**: si tenías una versión de prueba anterior, desinstálala primero y vuelve a instalar.
- **Un canal no abre**: prueba otro; si ninguno abre, revisa tu internet o contacta a StreamMID.
